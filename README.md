# 🚀 نظام فريق Trenz التسويقي المتكامل

نظام وكلاء ذكاء اصطناعي متكامل يعمل كفريق تسويقي احترافي لوكالة **Trenz** — وكالة تسويق وبرمجة وذكاء اصطناعي تعمل في سلطنة عُمان والخليج.

- **الاسم:** Trenz
- **التخصص:** التسويق الرقمي، البرمجة، حلول الذكاء الاصطناعي والأتمتة
- **السوق:** سلطنة عُمان والخليج العربي
- **اللغة:** العربية (فصحى + لهجة عُمانية/خليجية حسب السياق) والإنجليزية
- **العملاء النموذجيون:** عقارات، ترفيه وعائلات، عيادات طبية، مطاعم، شركات خدمية

## ⚙️ كيفية الاستخدام

1. **كمهارة في Claude:** ارفع مجلد الوكيل (`skills/trenz-*`) كـ Skill، فيتقمّص كلود دوره تلقائياً عند الطلب المناسب.
2. **كبرومبت نظام:** انسخ محتوى `SKILL.md` في بداية محادثة جديدة.
3. **كدليل تدريبي:** لتدريب موظفين حقيقيين على منهجية Trenz.

قبل كل مشروع، املأ **ملف العميل** الموجود في `_shared/BRAND.md`، ومرّر المخرجات بين الوكلاء حسب سير العمل أدناه.

## 🔄 سير العمل بين الوكلاء (Workflow)

```
بريف العميل
  ↓
كاتب المحتوى → مدقق المحتوى
  ↓
مصمم الجرافيك / المصور / مصمم الموشن / الممنتج
  ↓
كاتب صفحات الهبوط + المبرمج (إن وُجدت وجهة رقمية)
  ↓
كاتب الإيميلات (تتبّع وتحويل)
  ↓
مدير الحملات → محلل الحملات → تغذية راجعة لكاتب المحتوى
```

**القاعدة الذهبية:** لا يخرج أي محتوى للعميل قبل مروره على **مدقق المحتوى**.

## 📌 قواعد عامة تسري على جميع الوكلاء

1. **السياق العُماني أولاً:** المناسبات (اليوم الوطني، رمضان، خريف ظفار، الإجازات المدرسية)، العملة بالريال العُماني، وأسلوب مخاطبة يحترم ثقافة المجتمع.
2. **الازدواجية اللغوية:** المخرجات بالعربية، ويُضاف الإنجليزي عند الطلب أو للجمهور المزدوج.
3. **التسليم الجاهز للنشر:** لا مسودات ناقصة — كل مخرج يتضمن ما يحتاجه العميل (نص + هاشتاقات + CTA + توصية بصرية).
4. **التصعيد:** أي وكيل يواجه نقصاً في المعلومات يطرح أسئلة محددة قبل التنفيذ ولا يفترض.
5. **السرية:** بيانات العملاء لا تُذكر خارج سياق مشروعهم.

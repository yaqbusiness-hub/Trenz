## 🔄 سير العمل (Workflow)

```
طلب العميل (Brief)
      │
      ▼
كاتب المحتوى ──► مدقق المحتوى ──► المصمم الجرافيكي / الممنتج / الموشن
      │                                    │
      ▼                                    ▼
كاتب صفحات الهبوط ◄── المبرمج ◄── مدير الحملات الإعلانية
      │                                    │
      ▼                                    ▼
كاتب الإيميلات                    محلل الحملات ──► تقرير للعميل
```

**القاعدة الذهبية:** لا يخرج أي محتوى للعميل قبل مروره على **مدقق المحتوى**.

## 🎯 السياق العام لجميع الوكلاء

- **السوق:** سلطنة عُمان أولاً، ثم الخليج.
- **اللغة:** العربية الفصحى للمحتوى الرسمي، اللهجة الخليجية/العُمانية البيضاء عند الحاجة، والإنجليزية للعملاء الدوليين.
- **العملة:** ريال عُماني (ر.ع) — الأسعار تُكتب مثل: 5 ر.ع.
- **الثقافة:** احترام القيم الإسلامية والخصوصية الخليجية في كل المخرجات.
- **قطاعات عملاء Trenz:** العقارات، الترفيه والفعاليات، العيادات الطبية، المطاعم، التجزئة، الخدمات.

## 📌 كيفية الاستخدام

1. افتح ملف الوكيل المطلوب.
2. انسخ محتواه كـ System Prompt في Claude (أو كـ Skill/Project).
3. أعطه الـ Brief حسب قالب المدخلات الموجود في ملفه.
4. مرّر المخرجات بين الوكلاء حسب سير العمل أعلاه.
